# Becoming a Software Engineer in the AI Era

**A practical guide set for Sri Lankan university students**

> Last reviewed: September 2026 · Written and maintained by [@gayashan4lk](https://github.com/gayashan4lk)

AI tools can now write a first draft of most code. That has made some parts of a junior engineer's job smaller, and it has made other parts much more important: understanding systems, checking work, debugging, and explaining decisions to people.

These guides are for undergraduates in Sri Lanka at any university, whether state, private or overseas-affiliated. If you want a job as a software engineer, AI engineer, QA engineer, DevOps/cloud engineer or data/ML engineer, they cover what to learn, what to build and how to get hired.

Each guide is a **~10-minute read**. Each one stands alone, so read them in any order.

---

## The one idea behind every guide

> **Use AI, but learn first.**

AI makes you faster. It does not make you understand. When you struggled to find an answer on your own, understanding came as a side effect of the struggle. Now you get an answer in seconds, so you have to build the understanding **on purpose**.

Every guide has a **"Where AI fits"** section that says when to use AI and when to put it away. [Learning with AI](foundations/02-learning-with-ai.md) explains the reasoning and the evidence.

## Suggested reading order

The guides are topic-based, but this is a sensible order if you want one:

- **Year 1:** [00](00-the-landscape.md), then [02](foundations/02-learning-with-ai.md), [01](foundations/01-fundamentals-that-still-matter.md) and [03](foundations/03-engineering-habits.md). Build habits before you build a portfolio.
- **Year 2:** 04, 05 and 06, then read all five path guides (07–11) and pick one or two to aim at.
- **Before your internship** (usually Year 3): 12, 13 and 14.
- **Final year:** 14 again, then 15.

Starting late? Read 00 and 02 today, then go straight to the path guide you are aiming for.

## How each guide is structured

- **TL;DR:** the three things to remember.
- **Core sections:** practical, opinionated advice. Opinions are labelled as opinions.
- **Where AI fits:** when to use AI and when to go without it.
- **Do this next:** a short checklist you can start this week.
- **Build this:** 2–3 projects, from small to stretch.
- **Sri Lanka notes:** local context, where there is something useful to say.
- **Free resources:** a few good links, never paid-course promotion.

Numbers and research claims link to their source. Tools change every few months, so the guides teach **patterns** and mention tools only as examples.
